# HGL specification

HGL is a language for temporal computation. These documents define its language,
mandatory core, and optional standard library. Agreed rules and proposals retain
the status stated on each page; document examples do not establish executable
conformance.

This site follows the member revisions pinned by the HGL workspace. Each page
links to its repository source. Historical projects and audit records are not
part of the published specification.
